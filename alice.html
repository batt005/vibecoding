1. Основы Python

Python — интерпретируемый язык с динамической типизацией. Код выполняется сверху вниз.

# Привет, мир!
print("Привет, мир!")

# Переменные
name = "Анна"
age = 25
print(f"Меня зовут {name}, мне {age} лет.")

Задание: Напиши код, который выводит твоё имя и возраст в формате: «Меня зовут [имя], мне [возраст] лет».

Подсказка

Используй f-строку: f"Текст {переменная}".

2. Условия и циклы

Условные операторы и циклы позволяют управлять потоком выполнения программы.

age = 18
if age >= 18:
    print("Доступ разрешён")
else:
    print("Доступ запрещён")

# Цикл for
for i in range(3):
    print(f"Итерация {i}")

Задание: Напечатай числа от 1 до 5 с помощью цикла for.

Решение
for i in range(1, 6):
    print(i)

3. Функции

Функции позволяют переиспользовать код и делают его чище.

def greet(name):
    return f"Привет, {name}!"

message = greet("Мария")
print(message)

Задание: Создай функцию square(x), которая возвращает квадрат числа.

Решение
def square(x):
    return x * x

print(square(4))  # 16

4. Структуры данных

Основные структуры: списки, словари, множества.

# Список
numbers = [1, 2, 3, 4, 5]
print(numbers[0])  # 1

# Словарь
person = {"name": "Иван", "age": 30}
print(person["name"])  # Иван

Задание: Добавь в словарь person ключ "city" со значением "Москва". Выведи весь словарь.

Решение
person = {"name": "Иван", "age": 30}
person["city"] = "Москва"
print(person)

5. Работа с файлами

Чтение и запись файлов в Python.

# Запись в файл
with open("hello.txt", "w", encoding="utf-8") as f:
    f.write("Привет из Python!")

# Чтение из файла
with open("hello.txt", "r", encoding="utf-8") as f:
    content = f.read()
    print(content)

Задание: Запиши в файл data.txt строку «Это тестовый файл», затем прочитай и выведи содержимое.

Решение
with open("data.txt", "w", encoding="utf-8") as f:
    f.write("Это тестовый файл")

with open("data.txt", "r", encoding="utf-8") as f:
    print(f.read())

6. Практика: мини‑проект

Напиши программу, которая:

  1. Спрашивает у пользователя имя и возраст.
  2. Сохраняет данные в словарь.
  3. Выводит приветствие и сохраняет данные в файл users.txt.
Пример решения 
name = input("Введите имя: ")
age = input("Введите возраст: ")

user = {"name": name, "age": age}
print(f"Привет, {user['name']}! Тебе {user['age']} лет.")

with open("users.txt", "a", encoding="utf-8") as f:
    f.write(f"{user['name']}, {user['age']}\n")
